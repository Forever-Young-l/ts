# 《走进滕王阁序》· 80 秒电影分镜

## 艺术指导

不是游戏录屏，也不是方块建筑展示。镜头要像一个人真实走进古阁，先看见檐下幽暗，再被江天的光吸引。建筑负责提供尺度、遮挡和空间层次；山水负责呼吸；诗句负责情绪。

- 建筑材质：深黛瓦、旧朱漆、温润木色、青灰石材、少量哑金。木头要有纹理，石头要有风化感，瓦面要有细密的叠片秩序。
- 画面结构：前景用檐口、柱、栏杆构成框景；中景留给江面和乌篷船；远景用多层山影和云雾拉开距离。
- 镜头语言：第一人称、低速、克制。转向有预兆，停留有意义，不做无理由旋转或游戏式冲刺。
- 色彩曲线：雨后青灰 → 寒潭青绿 → 落霞绛金 → 暮色藕灰 → 深蓝月夜。
- 动态原则：云慢于鸟，水慢于舟，灯光只在暮色之后出现。每个动态元素都有节奏，不要所有东西同时抢镜。
- 画面禁忌：现代楼宇、汽车、路灯、电线、现代服饰、玻璃幕墙、霓虹、现代UI入画。

## 六境时间轴

### 00:00–00:11｜云销雨霁
原文：云销雨霁，彩彻区明

镜头从古阁檐下的暗部开始，沿木地板缓慢向前。朱柱和黛瓦形成近景框景，江面只露出一线。雨丝由密转疏，云层打开，天光从灰青转为浅金。

声音：屋檐滴水、极轻的风、低沉男声。不要急着铺满音乐。

### 00:11–00:23｜寒潭暮山
原文：潦水尽而寒潭清，烟光凝而暮山紫

镜头轻轻向左，掠过栏杆与木构细节，再抬向远山。水纹清晰但不闪烁，山影一层深于一层，雾气贴着山腰缓慢移动。

声音：水声渐近，古琴泛音进入，旁白句尾留白。

### 00:23–00:43｜落霞秋水
原文：落霞与孤鹜齐飞，秋水共长天一色

镜头完成登阁，抵达二层临江回廊。前景保留一角飞檐和栏杆，随后慢慢让开视野。孤鹜从霞光边缘掠过，江面出现狭长金色倒影。这里是全片视觉高潮，但色彩要克制，避免艳俗的橙红滤镜。

声音：男声沉稳诵读；箫声与古琴缓缓展开，句尾让音乐和江风接住。

### 00:43–00:56｜渔舟唱晚
原文：渔舟唱晚，响穷彭蠡之滨

镜头由天际缓慢俯向江面，追随一叶乌篷渔舟。船行速度很慢，灯笼只发出一小团温暖的光，不要像现代灯泡。

声音：橹入水、船身轻响、远处若隐若现的渔歌。

### 00:56–01:08｜雁阵惊寒
原文：雁阵惊寒，声断衡阳之浦

镜头从江面抬向暮空，雁阵由远及近，再飞向画面深处。天空由藕灰转深蓝，建筑只留下温柔的暗部轮廓。

声音：雁鸣、秋风、音乐开始收束。

### 01:08–01:20｜长江空流
原文：阁中帝子今何在？槛外长江空自流

镜头回到栏边，停止移动。画面中只保留远山、江水、几处微弱灯火。最后两秒不要再加新动作，让江水自己流动，画面自然淡出。

声音：男声完成最后一句，配乐退去，只留风和水。

## 朗诵脚本

使用成熟、沉静、略带磁性的普通话男声。不要播音腔过重，也不要戏剧化高腔。句前留半拍，句尾留一拍。

2. 00:12 潦水尽而寒潭清，烟光凝而暮山紫。

## 声音制作

- 旁白置于最前，音乐不压字。
- 配乐以古琴、箫、低弦氛围为主，不套用现成影视配乐。
- 环境音包括檐雨、风声、江水、木阶轻响、橹声和雁鸣。
- 最后保留约 1.5 秒自然声。
